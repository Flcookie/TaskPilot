# Deep Research Skill

## Goal
完成可追溯的深度研究任务，产出有信源支撑的报告。

## Recommended Workflow
1. 明确用户问题与研究边界
2. 拆分子问题，覆盖多个角度
3. 优先搜索一手信源和权威来源
4. 对关键结论做交叉验证
5. 提取证据与引用，区分事实和推断
6. 必要时使用 Python 做数据核对
7. 汇总并生成结构化报告

## Tool Policy
- web_search：发现资料，不要凭记忆编造 URL
- crawl / crawl_tool：读取来源正文
- local_search_tool：优先检索用户提供的本地资料
- python_repl：计算和数据核对

## Quality Rules
- 核心事实必须有来源
- 区分事实和推断
- 冲突来源需要显式说明
- 信息不足时继续检索，不要过早结束
