# Report Writing Skill

## Goal
把已收集的观察、引用和数据整理成结构清楚的报告。

## Recommended Workflow
1. 先列出已有事实和证据，不补充未验证信息
2. 按主题组织，而不是按工具调用顺序堆砌
3. 突出关键发现、限制和冲突来源
4. 保持与用户指定风格一致
5. 需要引用时保留原始 URL 或标题

## Tool Policy
- 默认不调用检索或代码工具
- 只使用当前任务已有的 observations、citations 和 plan 结果

## Quality Rules
- 严格依据已提供信息，不编造
- 事实和评论分开
- 结构清晰，便于读者扫读
- 有图或数据时说明来源
